# Support

## General installer bugs

Use the public issue tracker:

https://github.com/VisualStandard/visual-standard-installer/issues

Include the installer version, macOS version, Node.js version, the command used,
and the exact non-sensitive error message. Do not include a license key, entitlement
token, signed download URL, customer script, voiceover, or private project file.

## Security reports

Follow [SECURITY.md](SECURITY.md) and use GitHub private vulnerability reporting.

## Purchase, billing, or license delivery

Email [support@visualstandard.io](mailto:support@visualstandard.io) or use the
customer-support route published on the official Visual Standard website.
Do not post purchase details or license values in a public GitHub issue.
